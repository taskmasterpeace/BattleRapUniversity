## How Effectiveness is Applied

### Round Average Calculation

```
1. Battler A picks content types: [wordplay, schemes, punchlines]
2. Battler B picks content types: [gun_bars, street_talk, personals]

3. Calculate all matchups:
   wordplay vs gun_bars = 2.0x ✓
   wordplay vs street_talk = 1.0x
   wordplay vs personals = 1.0x
   schemes vs gun_bars = 1.0x
   schemes vs street_talk = 0.5x ✗
   schemes vs personals = 1.0x
   punchlines vs gun_bars = 1.0x
   punchlines vs street_talk = 1.0x
   punchlines vs personals = 1.0x

4. Average = (2.0 + 1.0 + 1.0 + 1.0 + 0.5 + 1.0 + 1.0 + 1.0 + 1.0) / 9
           = 10.5 / 9 = 1.17x

5. Battler A's effectiveness multiplier: 1.17x
```

### Applying to Scores

```
Base Score: 7.2
Effectiveness Multiplier: 1.17x
Adjusted Score: 7.2 × 1.17 = 8.42 (capped at 10.0)
```
