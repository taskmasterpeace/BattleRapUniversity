Auto Extract

For clean sprite sheets with consistent 5x8 grid. Automatically extracts all 40 characters.

Manual Crop

For problem sheets where characters overlap. Draw boxes around each character you want.

Auto Mode Instructions

  1. Drop your sprite sheet below (5 rows x 8 columns = 40 characters)
  2. Adjust settings if needed (tolerance, grid trimming)
  3. Click "Generate Command" to get the CLI command
  4. Run the command in terminal to extract sprites

Manual Mode Instructions

  1. Drop your sprite sheet below
  2. Click and drag to draw boxes around each character (boxes are square)
  3. Use "Undo" to remove last box, "Clear All" to start over
  4. Click "Generate Command" to get the CLI command
  5. Run the command in terminal to extract sprites
